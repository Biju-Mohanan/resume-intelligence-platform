# Roadmap

## Phase 0 — Foundation
- [x] Establish monorepo and product boundaries.
- [x] Document architecture, scope, security principles.
- [x] Create web and API application shells.
- [ ] Add CI, linting, and test conventions.

## Phase 1 — Career data and resume engine
- [ ] Canonical profile schema and evidence provenance.
- [ ] Resume CRUD, stable section IDs, ordering, visibility.
- [ ] Version snapshots and restore.
- [ ] DOCX import and safe parsing.
- [ ] Template renderer and PDF/DOCX export.

## Phase 2 — ATS and tailoring
- [ ] Explainable ATS rules and reports.
- [ ] Job-description parser and keyword coverage.
- [ ] Evidence-linked tailoring proposals.
- [ ] Approval and audit workflow.

## Phase 3 — Job intelligence
- [ ] Source adapter interface.
- [ ] Normalization, deduplication, freshness checks.
- [ ] Search, filters, matching, saved jobs.
- [ ] Application pipeline and reminders.

## Phase 4 — Career tools and agent access
- [ ] Cover letters and interview prep.
- [ ] Scoped REST API.
- [ ] MCP tools: list/read resumes, read format, write approved changes, search jobs, read job details.
- [ ] OAuth/PKCE or secure provider-managed identity integration.

## Phase 5 — Hardening and release
- [ ] Security review, tenant-isolation tests, backup/restore.
- [ ] Accessibility, performance, and browser testing.
- [ ] Deployment configuration and operational monitoring.
- [ ] Explicit deployment approval and provider setup.
